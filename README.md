# TeckStock - Gerenciador de estoque - web 1

Sistema de gerenciamento de estoque desenvolvido em Java Web utilizando JSP, PostgreSQL e arquitetura MVC.

## Tecnologias

- Java
- JSP
- PostgreSQL
- MVC
- NetBeans
- Glassfish

## Funcionalidades

- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Pesquisa de produtos
- Cadastro de lojas
- Cadastro de fornecedores

## Entidades

- Produto
- Loja
- Fornecedor
